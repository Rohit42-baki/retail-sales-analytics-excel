# retail-sales-analytics-excel
I analysed 4,200 retail orders (2020–2024) in Excel to answer one question: what really drives profit?     🔎 What I found   • Electronics = 60% of sales but only 39% of profit   • 12 of 42 products make 76% of profit   • Since 2022, orders fell while order value rose: growth now rests on fewer, larger orders   •
